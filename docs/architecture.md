# Architecture

Everything lives in one IIFE inside `index.html`.

## World generation

- Space is divided into square chunks of `C = 500` units on the x/z plane.
- Each chunk is generated by `gen(ix, iz)`, which seeds a small PRNG (`rng`) from `hash(ix, iz, seed)`. The same chunk and seed always produce the same cards and stars, so the world is deterministic and effectively infinite.
- Chunks near the camera target are created on demand and stored in a `Map` keyed `"ix,iz"`. Far chunks are evicted.
- A moved card is taken out of its chunk and kept in `pinned`, so it survives eviction.

## Rendering

- Canvas2D with a manual perspective projection: `toCam(x, y, z)` transforms into camera space, and `proj()` divides by depth to get screen coordinates.
- Every frame, visible items are depth-sorted (painter's algorithm) and drawn with distance fog.
- The faint grid floor and starfield give depth cues. The sky is pre-rendered by `makeSky()` per seed.
- After drawing, the screen rectangles of the cards are kept in `hits` for hover and drag picking.

## Input

- Pointer events handle mouse, pen and touch together. The number of active pointers and the modifiers pick the mode: `pan`, `rot`, `lift`, `card`, `cardY`, `pinch`.
- Momentum: drag velocities are smoothed into `vel` and decay after release.
- Keyboard: held keys are tracked in a `Set` and applied every frame.
- `goal` holds an animated camera target (used by **Home**) and eases toward it.

## Test hook

`window.__canvas` exposes a read-only view (`cam`, `chunks`, `pinned`, `hits`, `seed`, `dragMode`) so the Playwright suite can check state without scraping pixels. It changes no behavior.
