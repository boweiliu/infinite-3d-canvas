# Infinite 3D Canvas

A self-contained, dependency-free 3D infinite canvas in a single `index.html` (vanilla JS + Canvas2D perspective projection). Open it in a browser.

- Procedurally generated, seeded chunks of floating cards, grid floor and starfield
- Pan (drag), rotate (Shift/right-drag or Pan/Rotate toggle), zoom (wheel/pinch), WASD to move, Q/E up and down
- Drag cards around; Home and New seed buttons

**Status: work in progress.** Known issues: cards can't reliably be moved up and down, and parts of rotation don't work as intended.
